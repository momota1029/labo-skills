# Academic website operations

Read [website policy](references/website-policy.md). This skill owns both
webpage authoring and publication operations: it is reasonable for one
research institute to maintain talks, papers, profile, and a site.

Use the user's selected generator and deploy process. `loam-ssg` can be a
local backend choice, **not a mandatory public-policy dependency**. Always
review whether sources and claims are public before publishing. Do not push
unpublished research, private inbox files, or private skill contents to the
site.
