# Workspace writing rules

This directory holds user-maintained writing rules for this workspace. Give
each rule a clear scope, an actionable instruction, its basis, and any
exceptions or known conflicts. Add a checked date when the rule depends on
requirements that can change, such as a venue's submission instructions.

Corpus observations remain tentative until the user adopts them. When a
recurring preference is unresolved, the assistant can explain the evidence and
offer a concise rule for the user to add here. Keep personal author facts and
durable voice context in `profile/author-identity.md`.

The paper-writing skill reads this index and the applicable rule files for
writing tasks. Keep workspace-specific and field-specific rules here; durable
guidance that applies across fields belongs in the shared skill.
