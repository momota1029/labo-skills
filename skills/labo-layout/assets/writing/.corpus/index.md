# Corpus index

Add source entries here by field, language, manuscript type, or venue. Keep
author-voice samples distinct from shared field exemplars and current venue
instructions.

For each entry, include its stable ID, kind, source and version, precise
locator, useful style features, scope, and known limits. The paper-writing
skill uses a small relevant selection as soft evidence; this index does not
create style requirements by itself.

This entire index and its registration metadata are local-only, including
entries for open materials. Keep detailed selection records under local
`selections/<document>/corpus.toml`, outside tracked paper decisions.
