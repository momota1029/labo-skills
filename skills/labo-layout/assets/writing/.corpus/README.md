# Writing corpus

This workspace-level index holds prose examples and source references that can
inform manuscript style. It records descriptive evidence, not requirements.

For each source, record a stable ID, its kind (author-written sample, field
exemplar, or venue instruction), a workspace-relative path or citation, the
version and precise locator, its relevant scope, and limits on the comparison.
Note useful features such as terminology, phrasing, register, transitions,
sentence rhythm, and explanatory pacing.

Keep source files in their established manuscript or reference locations and
link to them here. Select only a few examples relevant to the current task.
Treat repeated patterns as soft style cues and learn the pattern without
copying distinctive wording or claims. Record examples selected for one paper
and the resulting judgments in that paper's
`writing/<paper>/decisions/corpus.toml` when such a record is used.
