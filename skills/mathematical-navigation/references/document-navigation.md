# 数学文書の参照・リンク・索引

講義、教科書、まとまった読書解説や数学原稿では、順に読めることと必要な箇所へ戻れる
ことを初稿から設計する。対象の指示と workspace の著者方針を先に確認する。色や索引の
言語などの明示指定は継続して適用し、完成直前の任意の装飾へ格下げしない。短い会話に
索引やファイル制作を持ち込まず、投稿先の書式や忠実な原文表示はそれぞれの範囲で保つ。

このファイルは [mathematical-navigation](../SKILL.md) の詳細規則である。
番号・見出し色・リンク・索引の要件をここで管理し、説明・教材制作のスキルから参照する。
文書の入口には、適用した規則へのリンク、実際の共通マクロ・索引登録の所在、
適用済み・残件を記した進捗へのリンクを短く置く。規則本文を各入口へ複製しない。

## 番号と参照を本文の文字列から分離する

- 定理、補題、定義、例、演習、節、図表、独立した表示数式と証明の段階には、文書の
  カウンタと意味に基づく安定ラベルを使う。定理環境の見出し、数式番号、本文中の
  参照番号を直打ちしない。並べ替え後も同じ対象を参照できるようにする。
- TeX では番号付き環境と `\label` を使い、本文からは `\ref`、`\eqref`、`\cref`
  などで参照する。段階には自動カウンタと一意なリンク先を用意する。証明ごとに番号を
  リセットしても PDF のアンカーが衝突しないようにする。重要な式を番号なし表示の
  まま置き、「上式」「先ほどの式」だけで後から指さない。
- 一続きの計算は式群全体に番号を付けられるが、個別に引用する行には固有のラベルを
  付ける。文中の変数や数値まで無意味に番号付けする必要はない。自作文書の参照番号を
  固定するための `\tag{数字}` や手動の「定理 2.3」は使わない。
- 原資料の式番号・定理番号・印刷頁は資料の位置情報であり、自作文書の番号とは別に
  保持する。原資料の版と位置を確認し、出典の参照として表示する。原番号を無理に
  自作文書のカウンタへ転用したり、直打ち検査で数学的な定数を誤修正したりしない。
- 台帳の安定 ID、TeX ラベル、読者に見える番号の役割を区別する。台帳に ID があっても
  PDF の参照が成立したことにはならない。

## 見出し・番号の色とリンク

講義・教科書では、定義・定理・補題・命題・系・例・演習などの定理環境の見出し
（種別名、自動番号、付記した名称）を、本文から見分けられる青色で示す。
数式の識別番号と Step 番号にも同じ方針を適用する。著者の指定色があればそれを使う。
本文や数式全体の文字色は、見出しと番号の設定から分けて管理する。

内部参照、目次、引用、URL、索引のリンクも青色で示す。本文中の「定理1.1」や
「式(1.1)」は自動参照で生成し、種別名を含めてリンクであることが分かる表示にする。
TeX のリンク色の設定だけでは定理環境の見出しや式の番号そのものは着色されない。
見出し・番号のスタイルとリンクの設定をそれぞれ用意し、文書の共通設定に集約する。
色を付けた見出しと実際のリンクを区別し、リンクから定義・主張・式・証明段階の
安定したアンカーへ移れることを確認する。

まとまった PDF には意味のある階層のしおりを備える。すべての式や Step をしおりへ
列挙する必要はない。索引から本文の定義へ、本文の重要語から対応する索引項目へなど、
必要な往復経路を設計する。リンクのために本文を別版へ複製しない。

## 索引を導入箇所とともに育てる

講義・教科書および索引を指定された文書では、定義・記号・記法・式を書く時点で索引情報を
登録する。本文が完成してから用語をまとめて推測抽出する手順にしない。短い原稿に
機械的に索引を追加する必要はないが、明示された索引要件は短さを理由に省略しない。

- **用語索引**：本文で定義した概念をすべて登録する。定義環境だけでなく、地の文・
  例・注で定義した概念も含む。一つの環境で複数の概念を定義した場合は各々を拾う。
  日本語資料では日本語見出しに英語を併記し、読みで配列する。定義を主な行き先とし、
  重要な性質や応用を必要に応じて追加する。同義語・表記揺れは参照先を統一する。
  英語の対応は実際の定義と出典に照らす。
- **記号・記法索引**：本文で導入・説明する数学記号と記法を網羅する。数体系・集合・
  空間の記号、写像・演算・関係、添字や括弧の約束、収束などの表記も対象とする。
  各項目には実際の数式表示、意味、対象の型や使用範囲、導入先を添え、同じ記号の
  異なる用法を区別する。「代表的な記号」だけを選ぶ方針に縮めない。同じ記法の出現を
  毎回別項目にする必要はなく、局所的な変数も固有の数学的意味・約束を導入するなら拾う。
  単に「$x,y$ を任意の実数とする」と置いた変数名自体は独立した記法ではない。
  そこで使う数体系、演算、量化の記法や、固有の意味を与えた記号を対象として照合する。
- **式の索引**：定義式、構成式、公式、評価式を名称・用途から引けるようにする。
  「主要式」という区分名を使っても、本文で意味を与えた式を少数だけに絞る理由には
  しない。式そのものと到達先を示し、記号一覧だけで数式索引を満たしたとしない。
  計算途中の各行をすべて別項目にする必要はなく、導出先の式や一続きの式群として
  登録できる。記号・記法と式を一つの索引の区分にするか別立てにするかは文書に合わせる。

表示名、読み、英語、意味、安定ラベルと索引先は、導入箇所のマクロや一つの登録元で
管理する。索引用の独立した数学本文を作らない。番号と頁は自動生成し、索引からは
定義・記法の導入箇所・式のアンカーへ移動できるようにする。頁へのリンクしかない場合は、
その制限を残件として区別する。数式が索引処理で失敗したときは保護・エスケープ・
生成方法を修正し、記号を削って意味の説明だけにすることを恒久的な解決にしない。

## 初稿・節の点検・組版をつなぐ

1. **執筆時**：証明の段階、参照先ラベル、用語・記号・記法・式の索引登録を本文と一緒に
   作る。自己点検で段階間の推論と参照先の内容を確認する。
2. **節をまとめるとき**：番号直打ち、未ラベルの環境・主要式、曖昧な参照、重複 ID、
   定義と索引の不一致を点検する。対象節の全定義と、導入した記号・記法・式を本文から
   拾い、登録元・索引項目・参照先と突き合わせる。未登録と未確認は項目と箇所を残す。
   件数が増えたことや抜き取りだけで網羅済みとはしない。文字列検索は候補抽出であり、
   地の文の定義や同じ環境内の別概念を読む点検に代わらない。数値・原資料の位置情報と
   内部参照を区別する。
3. **組版時**：必要な索引生成をビルド経路に含め、再組版後の参照・頁・索引を更新する。
   未解決参照、重複ラベル・宛先、索引の欠落・古い出力を確認する。実際の PDF で
   [共通の検査手順](pdf-checks.md)を使い、内部リンク・宛先・しおりの構造を毎回
   全体検査する。見出し・番号・リンクの色、クリック領域、索引の配列・英語・
   数式表示・改行と、代表的な定理・式・段階・索引・しおりの着地点は描画でも確認する。
   実際のビューア操作は初回の代表経路、変更や不具合の影響範囲を確認し、
   既に得た証拠を条件付きで再利用する。構造の成功だけで表示・意味・網羅性を
   確認済みにせず、差分がないことだけで未確認項目を完了にしない。

証明構造は mathematical-exposition と undergraduate-lecture、制作時の登録は reading-book
や reading-reference、索引の再生成と共通 PDF 検査の実行は各組版手順が担う。
検査方法と確認済み範囲の規則は本スキルに集約する。新しい会話や
別担当へ渡るときも、本文だけでなく未適用の規則・未確認の範囲を進捗に残す。
数学の正しさ、説明の追いやすさ、参照・索引の動作は別々に確認し、どれか一つの成功を
他の確認済みの根拠にしない。
