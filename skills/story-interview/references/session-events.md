# Session events

Unusual turns in a storyline session and what to do.

- **Resume.** Read the latest notes, restate the current state in a few lines,
  ask what changed. Reopen a resolved item only if its premise changed. Write a
  new dated file that links the previous one.
- **Restart.** Keep the old line under Superseded. Carry over only the decisions
  whose quoted passage survives; list the rest as dropped. Hear the new line
  whole (*listen-through*) before challenging.
- **Constraint conflict.** When a remedy would break a recorded constraint
  (submitted abstract, time slot), say so and offer the within-constraint and
  beyond-constraint options.
- **Late definition.** Revise the affected ledger rows, show them, and
  re-confirm only those.
- **"It is already written."** Find it and cite the locator. If found, the
  challenge becomes whether the line needs to say it; if not found, it stays open.
- **Contradiction.** Quote both statements and ask which stands; never
  overwrite the ledger silently.
- **Unplaced claim.** Record it under Unplaced claims with the support it
  needs; offer placements as options and leave the choice to the author.
- **Early stop.** Write the notes with queued and open items listed.
- **Language.** Keep quotations in the author's language.
