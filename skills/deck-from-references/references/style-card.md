# Style card

Fill one card per set of example decks, in the project. Look at the rendered
pages first; measure with `scripts/deck_audit.py`. Where examples differ, write
the source of each choice.

| Element | What the examples do | Taken from | Our choice |
|---|---|---|---|
| Page size and text size | measured: page size; median body word height / page width, per role (title, body, caption, source, closing, next question) | | |
| Words per page (median, max) | measured | | |
| Title form | claim, question or short noun phrase | | |
| Subtitle / lead line | what it carries | | |
| Position cue | roadmap pages, section tabs, progress bar | | |
| Transition devices | closing bar, turn pages, step reveals | | |
| Opening and ending pages | outline, speaker, references, outlook | | |
| Figures | share of page, caption, source tag | | |
| Formulas and definitions | statement style, citations beside claims | | |
| Colour roles | structure, contrast, roles, links | | |
| Top, bottom and next-question lines | the form of the sentences (full sentences? length) copied from the example pages | | |
| Bottom of the page | e.g. a bold conclusion line, then a next-question line in another colour | | |
| Key words | colour roles for terms inside a sentence (object, term, body) | | |
| Annotation device | boxed term with a small arrow to the part of the figure, numbered marks, callouts | | |
| Transformation device | thick arrow between panels, boxes joined by arrows | | |
| Sources and links on the page | none, a short credit, a footnote; how long | | |
| Share of the page taken by figures | measured or judged | | |
| What to avoid | | | |

Suggested defaults: at most about 150 words per page and a median body word
height of at least 1.75 percent of page width. These are starting points, not
measurements of reference decks; **replace them with the numbers measured on the user's own
example deck** (median words per page and its maximum, median word height over page width),
and compare each built page with them: a page far above the example's word count is the
usual sign that it is not in the user's manner, even when its text size matches.
Possible transition devices include a short question page before a definition
and a bottom bar carrying the scope of a claim or the next question.
