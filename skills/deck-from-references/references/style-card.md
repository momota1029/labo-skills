# Style card

Fill one card per set of example decks, in the project. Look at the rendered
pages first; measure with `scripts/deck_audit.py`. Where examples differ, write
the source of each choice.

| Element | What the examples do | Taken from | Our choice |
|---|---|---|---|
| Page size and text size | e.g. 16 x 9 cm, body about 11 pt | | |
| Words per page (median, max) | measured | | |
| Title form | claim, question or short noun phrase | | |
| Subtitle / lead line | what it carries | | |
| Position cue | roadmap pages, section tabs, progress bar | | |
| Transition devices | closing bar, turn pages, step reveals | | |
| Opening and ending pages | outline, speaker, references, outlook | | |
| Figures | share of page, caption, source tag | | |
| Formulas and definitions | statement style, citations beside claims | | |
| Colour roles | structure, contrast, roles, links | | |
| What to avoid | | | |

Suggested defaults: at most about 150 words per page and a median body word
height of at least 1.75 percent of page width. These are starting points, not
measurements of reference decks; calibrate them against the actual examples.
Possible transition devices include a short question page before a definition
and a bottom bar carrying the scope of a claim or the next question.
