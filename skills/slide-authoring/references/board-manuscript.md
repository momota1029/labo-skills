# Blackboard talk manuscripts

Use when the talk is given by writing on a board and the author wants a
speaker's manuscript instead of projected slides. Slide standards S1–S3 still
govern audience, story and pacing; this file adds the board format.

## Format

- One source builds two outputs: an explained version (board content, spoken
  text, calculation links, sources, backup answers, appendices) and a
  board-only version. A single switch (`\boardsonly`) selects the output; the
  board content is never maintained twice.
- The unit is a numbered **board** (板書): one argument, with its minutes and a
  rough line count. The text between rules is exactly what is written.
  Beneath it: what is said, how the board is used (what stays, what is erased),
  and the sources.
- A time table lists cumulative times and what has been shown by then. Add the
  delay plan: what to shorten at which lateness, and what is never shortened
  (the decisive estimate or comparison). If shortening drops a proof, say the
  talk then states it as a lemma and is no longer a proof of it.
- Questions get a backup entry per board and appendices for longer proofs.
  They are outside the main flow and use only the reserve time.

## Content

- Prove on the board only what carries the story; state standard inputs in the
  exact form used and cite them. Do not assert a theorem not opened or not
  proved as if it were.
- Mark status where the audience would otherwise assume more: unpublished
  draft, own-check only, independent review not done. Keep attribution exact,
  including joint work and problems that came from others.
- Time and line counts are design estimates until rehearsed. Name the boards to
  rehearse first (the longest derivation and the densest comparison).
- Keep a short review log: sources actually opened versus only cited,
  statements re-derived, gaps found, and what remains (rehearsal, author
  reading, independent review).

## Scope

The manuscript does not authorize edits to the underlying papers, sending or
publishing anything, or claims of novelty beyond the research-positioning
checkpoint already required for talks about the author's own results.
